Inter-Processor Communication Bridge
UART 921,600 baud
4-wire with RTS/CTS hardware handshake. ESP32-S3 (GPIO39/40) ↔ RPi Zero UART0. Carries packetized sensor readings, hazard flags, button events, and command acknowledgements.
GPIO Heartbeat 1Hz
RPi pulses GPIO every 1 second. If ESP32-S3 misses 3 pulses in a row, it determines Pi is dead and activates Power-Save mode, cutting 5V_PI rail cleanly.
SOS Bypass Path
Emergency SOS goes directly from ESP32-S3 UART to SIM7600G-H modem — completely bypassing Raspberry Pi and Linux OS. Fully functional even if Pi is off, crashed, or booting.

§ 3 — Data Flow Pipelines
5 Primary Signal Pathways
Each pathway has a distinct latency budget and failure fallback. The Hard Safety Path has strict 50ms deadline enforcement with hardware watchdog backup.

⚡ Reflex Hard Safety Path

Deterministic FreeRTOS — 50ms cycle — No OS dependencies

1
Sensor Input (Continuous)
Ultrasonic (GPIO trigger/echo) · ToF I2C 50Hz · IMU I2C 100Hz · PIR interrupt · Moisture ADC — all polled every 50ms FreeRTOS cycle.
2
FreeRTOS Priority Arbitration
5-level strict priority: Fall Spike → Drop-off (ToF) → Forward Obstacle → Water Immersion → Terrain. Highest active hazard wins each cycle.
3
Reflex Output (<15ms)
DRV2605L I2C → LRA haptic waveform in palm. Pattern encodes hazard: proximity ticks, curb double-pulse, water buzz, continuous SOS buzz.

🎥 Dual-Camera Vision Pipeline

Edge inference on RPi Zero 2W — 12-15fps — TFLite Int8

1
Dual Video Capture
CAM1 (OV5647 CSI-2 @ 30fps): forward scene — pedestrians, signs, crosswalks. CAM2 (UVC USB @ 30fps): downward — potholes, curbs, stairs, puddles.
2
On-Device Inference
YOLO-Fastest TFLite Int8 (object detection, 12fps) + MobileNetV3-SSD (pavement semantic segmentation). Runs entirely on Cortex-A53.
3
Spoken Guidance Output
festival TTS → BlueALSA → BT 5.x A2DP → bone-conduction earphone. "Pedestrian crossing 4 meters, wait." No hands required.

🎙️ Voice AI Assistant Flow

On-device ASR + Gemini cloud — conversational multimodal

1
Speech Capture
User holds Braille "V" → SPH0645LM4H top apex MEMS mic captures at 16kHz 24-bit. Tri-mic arch array suppresses wind noise via beamforming.
2
Whisper ASR → Gemini
Whisper.tflite runs on-device (offline capable). If LTE available: Gemini multimodal API processes audio + current camera frame snapshot for richer contextual answers.
3
Audio Response to Ear
BT 5.x A2DP → bone-conduction headset. Ears stay unblocked; user maintains full ambient spatial awareness while listening to AI response.

🆘 Autonomous SOS Dispatch

Fail-safe — works with Pi OFF — <5 seconds total

1
Trigger: Button or Fall
2-second guarded SOS button hold, OR IMU detects freefall spike + post-fall inactivity + PPG biometric distress. 5-second haptic cancel window.
2
ESP32-S3 → Modem Direct
ESP32-S3 UART → SIM7600G-H: acquire GPS NMEA fix → AT+CMGS sends SMS with Google Maps pin to 3 emergency contacts. Bypasses Raspberry Pi completely.
3
Multi-Channel Alert Dispatch
Simultaneous: SMS to 3 contacts + Voice call to 112 + 92dBA siren from MAX98357A + Firebase cloud incident push (when online).

🔋 Multi-Rail Power Distribution & Shedding

4-stage autonomous power state machine — 6800mAh 1S2P — 36h+ Power-Save runtime

1
Battery → VSYS (3.0–4.2V)
2× NCR18650GA 1S2P. BQ25895 USB-C PD charge controller. BQ27441 fuel gauge on I2C. PCM/BMS for overcurrent, over-discharge, thermal protection.
2
3 Regulators → 5 Rails
TPS63020 Buck-Boost → 3V3_MAIN (always-on safety). TPS61088 Boost → 5V_PI + 5V_AUX (switchable). Direct fused rails for VBAT_MODEM and VBAT_MOTOR.
3
TCA9555 → Rail Load Switching
I2C expander drives TPS22918 switches. When SOC <20%: cuts 5V_PI (Pi + cameras). Ultrasonic, ToF, IMU, PIRs, haptics remain ON → 36h+ battery life.

Power State Machine
4-Stage Autonomous Power Management
🟢 NORMAL (>25% SOC)
All AI, dual cameras, Bluetooth, LTE active. Full system capability. ~1.4A total draw.
🟡 POWER-SAVE (<20% SOC)
Cuts 5V_PI (Pi + cameras). Safety sensors + haptics + ultrasonic remain ON. 36h+ runtime. ~180mA draw.
🔴 SOS MODE
Forces VBAT_MODEM on regardless of battery level. Continuous GPS + LTE beaconing until help arrives or battery dies.
🔵 CHARGING
BQ25895 USB-C PD handles CC/CV charging. System can operate normally while charging. Fuel gauge tracks SOC in real-time.
