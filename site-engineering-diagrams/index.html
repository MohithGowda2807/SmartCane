§ 2 — Data Flow Diagrams
5 Primary Signal Flow Paths
Each path has a distinct latency budget and failure fallback. The Hard Safety Path (red) is the only path with strict 50ms deadline guarantees.

⚡ Reflex Hard Safety Path (<50ms)

Deterministic FreeRTOS — 20Hz — No OS dependencies

1
Sensor Input (Continuous)
Ultrasonic (GPIO trigger/echo) · ToF I2C · IMU I2C · PIR interrupt · Moisture ADC — all polled or interrupt-driven every 50ms
2
FreeRTOS Priority Arbitration
Strict 5-level priority: Fall Spike → Drop-off (ToF) → Forward Obstacle → Water Immersion → Terrain. Highest active hazard wins in each 50ms cycle.
3
Reflex Output (<15ms)
DRV2605L I2C command → LRA haptic vibration waveform in palm. Pattern encodes hazard type: proximity ticks, curb double-pulse, water buzz, continuous SOS.

🎥 Dual-Camera Vision Pipeline

Edge inference on RPi — 12-15fps — TFLite Int8 quantized

1
Dual Video Capture
CAM1 (OV5647 CSI-2): scene, signs, pedestrians, crosswalks at 30fps. CAM2 (UVC USB): downward pavement, curbs, stairs, potholes at 30fps.
2
On-Device Inference
YOLO-Fastest TFLite Int8 for object detection (12fps). MobileNetV3-SSD for semantic segmentation of pavement surface classes.
3
Audio Guidance Output
Text-to-Speech via BlueALSA → bone-conduction Bluetooth earphone. E.g., "Pedestrian crossing 4 meters, wait." No hands needed.

🎙️ Voice AI Assistant Flow

On-device ASR + Cloud Gemini — conversational multimodal

1
Speech Capture
User holds Braille "V" button → SPH0645LM4H top apex MEMS mic captures at 16kHz, 24-bit. Arch tri-mic array suppresses wind noise via beamforming.
2
Whisper ASR → Gemini
Whisper.tflite runs on-device (offline capable). If LTE available, query Gemini multimodal API with audio + camera frame snapshot for richer answers.
3
Audio Response to Ear
Bluetooth 5.x A2DP → bone-conduction headset. Ears stay open; user maintains full spatial awareness of ambient environment while listening.

🆘 Autonomous SOS Dispatch

Fail-safe path — operates with Pi OFF — <5 seconds total

1
Trigger: Button or Fall
2-second guarded SOS button hold, OR IMU detects freefall spike + post-fall inactivity + PPG biometric distress. 5-second haptic cancel window.
2
ESP32-S3 → Modem Direct
ESP32-S3 UART → SIM7600G-H: acquire GPS NMEA fix (<30s hot) → send AT+CMGS SMS with coordinates to 3 emergency contacts.
3
Multi-Channel Alert
Simultaneously: SMS to 3 contacts + Voice call to 112 (India emergency) + 92dBA siren from MAX98357A + Cloud incident push when online.

🔋 Multi-Rail Power Distribution & Shedding

4-stage autonomous power state machine — 6800mAh 1S2P Li-Ion — 36h+ Power-Save runtime

1
Battery → VSYS (3.0V–4.2V)
2× NCR18650GA cells in 1S2P. BQ25895 USB-C PD charge controller. BQ27441 fuel gauge on I2C. PCM/BMS for short circuit and over-discharge protection.
2
Regulation → 3 Regulators
TPS63020 Buck-Boost → 3V3_MAIN (always-on). TPS61088 Synchronous Boost → 5V_PI + 5V_AUX (switchable). Direct fused rails for modem + motor.
3
TCA9555 → Rail Load Switching
I2C expander drives TPS22918 load switches on each rail. When SOC <20%: gates off 5V_PI (Pi + cameras). Ultrasonic, ToF, IMU, PIRs, haptics remain ON for 36h+.
